# HUB 2.0 原型（Avant 智慧巡检）

 2.0 静态 HTML 原型合集，可本地打开或通过 GitHub Pages 在线预览。

## 在线访问

启用 GitHub Pages 后：

| 入口 | 地址 |
| --- | --- |
| **原型导航门户** | [hub20-prototype 根路径](https://xinyulivia.github.io/hub20-prototype/) |
| 巡检驾驶舱 | [home-dashboard.html](https://xinyulivia.github.io/hub20-prototype/home-dashboard.html) |
| 项目首页 | [project-home.html](https://xinyulivia.github.io/hub20-prototype/project-home.html) |

## 模块一览

- 全局驾驶舱 / 项目首页
- 摄像头接入（列表、详情、监控、回放、告警等）
- 事件联动处置 2.0（工作流、告警、操作日志等）
- 任务实况 / 检测区域配置 / 平台设备管理 等

## 本地预览

用任意静态服务器打开本目录即可，例如：

```powershell
npx --yes serve .
```

或直接双击打开 [index.html](./index.html)。
